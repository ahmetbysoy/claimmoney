    48→    48→## 1. Bağlam ve Geçiş Özeti
    49→    49→
    50→    50→Mevcut **ClaimMoney** projesi, sunucu taraflı çalışan bir Tierflow mikro-yapı motoru üzerine kuruludur. `src/lib/engine/` altındaki 17 ana modül, 10 dedektör, 8 feature builder, 2 kitap servisi, 4 strateji modülü, 3 risk modülü, 2 execution modülü ve 2 performans modülü içerir.
    51→    51→
    52→    52→**BOZOK PRO v4.0**, bu motoru tamamen tarayıcı içine taşır. Sunucu taraflı işleme sona erer; tüm L2 veri işleme, dedektör çalıştırma, sinyal üretimi ve plan yönetimi bir **Inline Web Worker** içinde gerçekleşir. Frontend, mevcut shadcn/ui demo dashboard'ı yerine 8 panel koyu tema terminal arayüzüyle değiştirilir.

    82→    82→## 2. Mimari
    83→    83→
    84→    84→```mermaid
    85→    85→flowchart TB
    86→    86→  subgraph MainThread[Ana İş Parçacığı (UI)]
    87→    87→    WS[WebSocket Manager] -->|cmd: book,trade,liq| Worker[Inline Web Worker]
    88→    88→    Worker -->|state diff @200ms| Store[Zustand Store]
    89→    89→    Store --> UI[8 Panel Terminal UI]
    90→    90→    UI -->|armPlan, cancelPlan, config| Worker
    91→    91→  end
    92→    92→
    93→    93→  subgraph WorkerThread[Web Worker (Motor)]
    94→    94→    Worker --> RB[Ring Buffers]
    95→    95→    RB --> BK[Order Book State]
    96→    96→    RB --> FT[Feature Engine]
    97→    97→    FT --> Det[Detector Registry - 16 Tip]
    98→    98→    Det --> CE[Confluence Engine]
    99→    99→    CE --> RG[Risk Gates]
   100→   100→    RG --> RR[Net RR Calculator]
   101→   101→    RR --> PSM[Plan State Machine]
   102→   102→    PSM --> PP[Paper Performance Tracker]
   103→   103→    PSM --> WH[Webhook Dispatcher]
   104→   104→    Det --> RV[Regime Classifier]
   105→   105→    RV --> NR[Narrative Generator]
   106→   106→  end
   107→   107→```
   108→   108→
   109→   109→### Temel Mimari Kurallar
   110→   110→
   111→   111→1. **Worker tek gerçeklik kaynağıdır** — tüm L2 veri işleme, sinyal üretimi, plan yönetimi worker içinde gerçekleşir
   112→   112→2. **Typed array'ler zorunludur** — `Float64Array`, `Uint8Array`, `Uint16Array` ile tüm state, GC baskısını minimize eder
   113→   113→3. **Ring buffer'lar sabit boyutludur** — trades (512), CVD (128), flow (64), liquidations (256), signals (128)
   114→   114→4. **State sync 200ms throttled** — worker → main thread iletişimi diff tabanlı, 200ms aralıklı
   115→   115→5. **Plan kullanıcı onayı gerektirir** — otomatik işlem yok; NEUTRAL → CANDIDATE → ARMED akışı
   116→   116→6. **Tüm fiyatlar tick normalize edilir** — borsa tick size'ına göre yuvarlama zorunlu

   120→   120→## 3. Inline Web Worker (P0)
   121→   121→
   122→   122→**Öncelik:** Kritik — Tüm motorun çalışma ortamı
   123→   123→**Mevcut Referans:** `src/lib/engine/market-runtime.ts`, `src/lib/engine/tierflow-runtime.ts`
   124→   124→
   125→   125→### 3.1 State Yönetimi (Typed Arrays)
   126→   126→
   127→   127→Worker içi tüm durum, heap allocation olmadan typed array'lerde tutulur:
   128→   128→
   129→   129→```ts
   130→   130→// worker-state.ts
   131→   131→interface WorkerState {
   132→   132→  // Order Book: 50 seviye (bid + ask)
   133→   133→  bidPrices: Float64Array;   // [50]
   134→   134→  bidQties: Float64Array;    // [50]
   135→   135→  askPrices: Float64Array;   // [50]
   136→   136→  askQties: Float64Array;    // [50]
   137→   137→  prevBidPrices: Float64Array; // önceki frame (velocity için)
   138→   138→  prevBidQties: Float64Array;
   139→   139→  prevAskPrices: Float64Array;
   140→   140→  prevAskQties: Float64Array;
   141→   141→
   142→   142→  // Ring Buffers
   143→   143→  tradeRing: { prices: Float64Array; qties: Float64Array; sides: Uint8Array; ts: Float64Array; head: number; size: number }; // 512
   144→   144→  cvdRing: { values: Float64Array; ts: Float64Array; head: number; size: number }; // 128
   145→   145→  flowRing: { buyN: Float64Array; sellN: Float64Array; delta: Float64Array; ts: Float64Array; head: number; size: number }; // 64
   146→   146→  liqRing: { sides: Uint8Array; prices: Float64Array; notional: Float64Array; ts: Float64Array; head: number; size: number }; // 256
   147→   147→  signalRing: { types: Uint16Array; confs: Float64Array; dirs: Uint8Array; ts: Float64Array; head: number; size: number }; // 128
   148→   148→}
   149→   149→```
   150→   150→
   151→   151→### 3.2 Worker Mesaj Protokolü
   152→   152→
   153→   153→```ts
   154→   154→// Worker'a gelen komutlar (main thread → worker)
   155→   155→type WorkerCmd =
   156→   156→  | { type: 'book'; bids: [number, number][]; asks: [number, number][]; ts: number; seq: number }
   157→   157→  | { type: 'trade'; price: number; qty: number; side: 'buy' | 'sell'; ts: number }
   158→   158→  | { type: 'liq'; side: 'buy' | 'sell'; price: number; notional: number; ts: number }
   159→   159→  | { type: 'config'; cfg: WorkerConfig }
   160→   160→  | { type: 'armPlan'; planId: string }
   161→   161→  | { type: 'cancelPlan'; planId: string }
   162→   162→  | { type: 'reset' };
   163→   163→
   164→   164→// Worker'dan çıkan mesajlar (worker → main thread)
   165→   165→type WorkerMsg =
   166→   166→  | { type: 'state'; diff: StateDiff; ts: number }
   167→   167→  | { type: 'plan'; plan: PlanState }
   168→   168→  | { type: 'signal'; signal: SignalRecord }
   169→   169→  | { type: 'fill'; fill: FillRecord }
   170→   170→  | { type: 'narrative'; text: string; regime: RegimeInfo }
   171→   171→  | { type: 'error'; msg: string };
   172→   172→```
   173→   173→
   174→   174→### 3.3 Diff Tabanlı State Sync
   175→   175→
   176→   176→Worker her 200ms'de bir state snapshot gönderir. Sadece değişen alanlar `StateDiff` içinde iletilir:
   177→   177→
   178→   178→```ts
   179→   179→interface StateDiff {
   180→   180→  bookChanged: boolean;
   181→   181→  bestBid?: number; bestAsk?: number;
   182→   182→  spreadBps?: number;
   183→   183→  midPrice?: number;
   184→   184→  tradesAdded: number;     // son sync'ten bu yana eklenen trade sayısı
   185→   185→  signalsAdded: number;
   186→   186→  planChanged: boolean;
   187→   187→  regimeChanged: boolean;
   188→   188→  regime?: RegimeInfo;
   189→   189→  narrativeChanged: boolean;
   190→   190→  narrative?: string;
   191→   191→  // ... sadece değişen metrikler
   192→   192→}
   193→   193→```

   197→   197→## 4. Plan Durum Makinesi (P0)

   201→   201→
   202→   202→### 4.1 Durumlar
   203→   203→
   204→   204→```ts
   205→   205→type PlanState = 'NEUTRAL' | 'CANDIDATE' | 'ARMED';
   206→   206→
   207→   207→type Plan = {
   208→   208→  id: string;
   209→   209→  state: PlanState;
   210→   210→  direction: 'LONG' | 'SHORT';
   211→   211→  entry: number;
   212→   212→  stopLoss: number;
   213→   213→  takeProfit: number;
   214→   214→  netRR: number;
   215→   215→  confidence: number;
   216→   216→  confluenceCount: number;
   217→   217→  confluenceTypes: SignalType[];
   218→   218→  createdAt: number;
   219→   219→  ttl: number;              // varsayılan 30.000ms
   220→   220→  expiresAt: number;
   221→   221→  signalIds: string[];
   222→   222→};
   223→   223→```
   224→   224→
   225→   225→### 4.2 Geçiş Kuralları
   226→   226→
   227→   227→```mermaid
   228→   228→stateDiagram-v2
   229→   229→  [*] --> NEUTRAL
   230→   230→  NEUTRAL --> CANDIDATE : confluence >= 3 && netRR >= 2.0 && riskGatePass
   231→   231→  CANDIDATE --> ARMED : kullanıcı ARM butonu
   232→   232→  CANDIDATE --> NEUTRAL : TTL sona erdi / yeni sinyal çelişiyor
   233→   233→  ARMED --> NEUTRAL : kullanıcı CANCEL / TTL sona erdi / fill tamamlandı
   234→   234→  ARMED --> NEUTRAL : fill tamamlandı (paper execution devralır)
   235→   235→```
   236→   236→
   237→   237→- **CANDIDATE oluşturma koşulları:**
   238→   238→  - En az **3 benzersiz sinyal tipi** aynı yönde, 30 saniye penceresi içinde
   239→   239→  - **Net RR >= 2.0** (bölüm 7'ye bak)
   240→   240→  - Tüm risk kapıları geçmiş (bölüm 5'e bak)
   241→   241→
   242→   242→- **Otomatik sonlanma:**
   243→   243→  - TTL varsayılan **30 saniye**. Son 5 saniyede UI'da görsel uyarı
   244→   244→  - Aynı yönde yeni CANDIDATE oluşturulmaz (30 saniye cooldown)
   245→   245→
   246→   246→- **ARM mekanizması:**
   247→   247→  - Kullanıcı sadece CANDIDATE durumundaki planları onaylayabilir
   248→   248→  - ARM butonu UI'de her zaman görünür (Panel 5 - LEVELS)
   249→   249→  - ARM sonrası paper execution tetiklenir

   253→   253→## 5. Risk Kapıları (P0)
   254→   254→
   255→   255→**Öncelik:** Kritik — Plan oluşturmadan önceki zorunlu kontrol
   256→   256→**Mevcut Referans:** `src/lib/engine/strategy/filters.ts`
   257→   257→
   258→   258→Her CANDIDATE oluşturulmadan önce şu 5 kapıdan geçilmelidir. Herhangi biri başarısız olursa plan oluşturulmaz:
   259→   259→
   260→   260→| # | Kapı | Koşul | Başarısız Mesajı |
   261→   261→|---|---|---|---|
   262→   262→| 1 | **Veri Tazelik** | Son book güncellemesinden bu yana < 5 saniye | `STALE_DATA` |
   263→   263→| 2 | **Spread Kontrolü** | Spread <= 10 bps | `SPREAD_TOO_WIDE` |
   264→   264→| 3 | **VPIN Toksisite** | VPIN <= 0.8 | `VPIN_TOXIC` |
   265→   265→| 4 | **Sıkıştırma Kontrolü** | Aktif sıkıştırma yok | `COMPRESSION_ACTIVE` |
   266→   266→| 5 | **Kademeli Tasfiye** | Son 5 saniye içinde aktif cascade yok | `CASCADE_RECENT` |
   267→   267→
   268→   268→```ts
   269→   269→interface RiskGateResult {
   270→   270→  passed: boolean;
   271→   271→  failedGate: string | null;   // 'STALE_DATA' | 'SPREAD_TOO_WIDE' | ...
   272→   272→  details: Record<string, number>; // { staleMs: 3200, spreadBps: 4.2, vpin: 0.45, ... }
   273→   273→}
   274→   274→```
   275→   275→
   276→   276→Kapı sonuçları UI'da Panel 5'te (LEVELS) her CANDIDATE plan kartında gösterilir.

   285→   285→### 6.1 Sinyal Tipleri (16 adet)

   287→   287→```ts
   288→   288→type SignalType =
   289→   289→  | 'WALL'           // Duvar dedektörü (bid_wall, ask_wall)
   290→   290→  | 'SPOOFING'       // Sahte duvar
   291→   291→  | 'CVD_DIV'        // CVD diverjansı
   292→   292→  | 'ABSORPTION'     // Emilim
   293→   293→  | 'COMPRESSION'    // Sıkıştırma
   294→   294→  | 'CASCADE'        // Kademeli tasfiye
   295→   295→  | 'ICEBERG'        // Gizli likidite
   296→   296→  | 'VOID'           // Likidite boşluğu
   297→   297→  | 'FLOW_SUSTAINED' // Sürekli akış
   298→   298→  | 'LADDER'         // Merdiven yapısı
   299→   299→  | 'BOOK_SKEW'      // Kitap eğilimi
   300→   300→  | 'SKEW_DIVERGENCE'// Çok katmanlı sapma
   301→   301→  | 'TAPE_SPIKE'     // Tape sıçraması
   302→   302→  | 'DELTA_EXPANSION'// Delta genişlemesi
   303→   303→  | 'FLOW_EXHAUSTION'// Akış tükenmesi
   304→   304→  | 'LIQ_CLUSTER';   // Tasfiye kümesi
   305→   305→```
   306→   306→
   307→   307→### 6.2 Konflüans Hesaplama
   308→   308→
   309→   309→```ts
   310→   310→interface ConfluenceResult {
   311→   311→  count: number;               // benzersiz tip sayısı
   312→   312→  types: SignalType[];         // benzersiz tipler listesi
   313→   313→  direction: 'LONG' | 'SHORT';
   314→   314→  windowStart: number;         // 30s pencere başlangıcı
   315→   315→  confidenceBoost: number;     // konflüans bonusu
   316→   316→}
   317→   317→
   318→   318→function calculateConfluence(signals: SignalRecord[], now: number): ConfluenceResult;
   319→   319→```
   320→   320→
   321→   321→- **Pencere:** Son 30 saniye içindeki tüm aktif sinyaller
   322→   322→- **Süre:** `signalDecay` ile hesaplanan decayed confidence > 20 olan sinyaller sayılır
   323→   323→- **Benzersiz tip:** Aynı `SignalType` tekrar sayılmaz
   324→   324→- **Yön:** En çok sinyal olan yön seçilir (eşitlik durumunda konflüans geçersiz)
   325→   325→
   326→   326→### 6.3 Konflüans Bonusu
   327→   327→
   328→   328→| Konflüans Sayısı | Bonus |
   329→   329→|---|---|
   330→   330→| 3 | +0 (taban) |
   331→   331→| 4 | +15 confidence puanı |
   332→   332→| 5+ | +25 confidence puanı |

   336→   336→## 7. Net RR Hesaplayıcı (P0)
   337→   337→
   338→   338→**Öncelik:** Kritik — Gerçekçi risk-ödül oranı
   339→   339→**Mevcut Referans:** `src/lib/engine/risk/tradePlanner.ts`, `src/lib/engine/fee-accounting.ts`
   340→   340→
   341→   341→Brüt RR'den aşağıdaki maliyetler düşülerek net RR hesaplanır:
   342→   342→
   343→   343→```ts
   344→   344→interface NetRRCalculation {
   345→   345→  grossRR: number;          // giriş öncesi ham RR
   346→   346→  roundTripFeeBps: number;  // yapılandırılabilir, varsayılan 4 bps
   347→   347→  avgSlippageBps: number;   // varsayılan 5 bps
   348→   348→  fundingCostBps: number;   // saat başına maliyet * beklenen tutma süresi
   349→   349→  netRR: number;            // sonuç
   350→   350→}
   351→   351→
   352→   352→function calculateNetRR(
   353→   353→  entry: number,
   354→   354→  stopLoss: number,
   355→   355→  takeProfit: number,
   356→   356→  config: { roundTripFeeBps: number; avgSlippageBps: number; fundingRatePerHour: number; expectedHoldHours: number }
   357→   357→): NetRRCalculation;
   358→   358→```
   359→   359→
   360→   360→**Formül:**
   361→   361→```
   362→   362→netRR = grossRR - roundTripFeeBps - avgSlippageBps - (fundingRatePerHour * expectedHoldHours)
   363→   363→```
   364→   364→
   365→   365→**Zorunlu koşul:** `netRR >= 2.0` — Aksi halde plan oluşturulmaz.
   366→   366→

   635→   635→## 19. Gerçek Kelly Pozisyon Boyutlandırma (P1)
   636→   636→
   637→   637→**Öncelik:** Yüksek
   638→   638→**Mevcut Referans:** `src/lib/engine/risk/positionSizer.ts`
   639→   639→
   640→   640→```ts
   641→   641→interface KellyResult {
   642→   642→  kellyFraction: number;       // W - (1-W)/R
   643→   643→  halfKelly: number;           // kellyFraction / 2
   644→   644→  confidenceAdjusted: number;  // halfKelly * (confidence / 100)
   645→   645→  finalFraction: number;       // min(confidenceAdjusted, maxRiskPct)
   646→   646→  positionSize: number;        // capital * finalFraction
   647→   647→  winRate: number;             // W
   648→   648→  rrRatio: number;             // R
   649→   649→}
   650→   650→```
   651→   651→
   652→   652→**Formül:**
   653→   653→```
   654→   654→kelly = W - (1 - W) / R
   655→   655→halfKelly = kelly / 2
   656→   656→confidenceAdjusted = halfKelly * (confidence / 100)
   657→   657→finalFraction = min(confidenceAdjusted, maxRiskPct)   // hard cap
   658→   658→positionSize = capital * finalFraction
   659→   659→```
   660→   660→
   661→   661→- **Half-Kelly cap:** Kelly formülünün sonucu her zaman 2'ye bölünür
   662→   662→- **Güven ayarlaması:** Sinyal güven skoru ile çarpılır (0-100 arası)
   663→   663→- **Hard cap:** Hesaplanan değer, yapılandırılabilir maksimum risk yüzdesini (varsayılan %2) aşamaz
   664→   664→

   706→   706→  'BID_WALL': 0.0002,
   707→   707→  'ASK_WALL': 0.0002,
   708→   708→  'SPOOFING': 0.002,       // hızlı çürür
   709→   709→  'CASCADE_CHAIN': 0.003,  // hızlı çürür
   710→   710→  'CASCADE_EXHAUSTED': 0.003,
   711→   711→  'CVD_DIV': 0.003,        // hızlı çürür
   712→   712→  'VOID': 0.0008,
   713→   713→  'VOID_FILLING': 0.0008,
   714→   714→  'ICEBERG': 0.0003,
   715→   715→  'DEFAULT': 0.0005,
   716→   716→};

   816→   816→interface SpoofConfirmation {
